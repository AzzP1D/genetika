# Генетика — путь «от молекулы к признаку»

Тренажёр по генетике и молекулярной биологии для учащихся 9–11 классов: интерактивные 3D-уроки и задачи с разбором типичных ошибок.

**Открыть в браузере:** https://azzp1d.github.io/genetika/

Работа для республиканского конкурса «Компьютер. Образование. Интернет» (КОИ-2026), номинация «Дидактический конструктор: система учебных модулей».

## Что внутри
- `app/` — само приложение (HTML, JavaScript, библиотека Three.js). Работает в браузере; для Android оборачивается в приложение с помощью Capacitor.
- `blender/` — скрипты, которыми построены собственные 3D-модели органоидов (Blender 5.2).
- `tools/` — вспомогательные скрипты.

Все 3D-модели созданы для этого проекта. Разработка велась автором с использованием ИИ-инструмента Claude Code (Anthropic).

## Данные о строении молекул
Формы белков и ДНК в крупных планах построены по экспериментальным структурам банка белков RCSB PDB (rcsb.org; данные банка — общественное достояние, CC0). Сами модели сделаны для этого проекта скриптами из папки `blender/`.
- 1KX5 — нуклеосома (Davey et al., 2002).
- 1JFF — тубулин (Löwe et al., 2001); 1J6Z — актин (Otterbein et al., 2001); 3KIN — кинезин (Kozielski et al., 1997).
- Кинетохор в уроке «Митоз»: 3IZ0 — комплекс Ndc80 на микротрубочке (Alushin et al., 2010); 2VE7 — комплекс Ndc80 (Ciferri et al., 2008); 5LSK — комплекс Mis12 (Petrovic et al., 2016); 7R5S — внутренний кинетохор CCAN (Yatskevich et al., 2022); 3AN2 — нуклеосома с CENP-A (Tachiwana et al., 2011); 1GO4 — Mad1–Mad2 (Sironi et al., 2002); 4AEZ — комплекс контрольной точки MCC (Chao et al., 2012).

## Кинетохор на хромосоме

Крупный план кинетохора обновлён 16.11.2026: [8PPR](https://www.rcsb.org/structure/8PPR) — экспериментальный узел Spc24/Spc25–MIS12–KNL1/ZWINT (Yatskevich et al., 2024, CC0; [статья](https://doi.org/10.1038/s41594-024-01249-y)). Взаимные координаты цепей внутри этого узла сохранены. Опорная точка CENP-C перенесена из 5LSK совмещением 199 CA-атомов MIS12 (RMSD 0,228 нм). Это совмещение **не** делает общую сборку экспериментально определённой: структура 8PPR представляет автоингибированное состояние MIS12, поэтому связь с CENP-C в учебной модели является реконструкцией активного пути прикрепления, а не исходной сборкой 8PPR.

Гибкие участки CENP-C, длинный участок Ndc80, взаимное положение отдельных CCAN и центромерных нуклеосом, соединительная ДНК и укладка двухроматидной хромосомы реконструированы для учебной визуализации. Хромосома не имеет мембраны; гладкая прозрачная сферическая подложка удалена. Геометрия поверхности хроматина не означает наличия универсальной регулярной фибриллы. Масштабы молекул сохранены, но размеры и упаковка целой хромосомы иллюстративны. Источники также доступны по кнопке «О модели» в образце кинетохора.

Сборка: `blender/models/kinetochore_junction.py` и `blender/models/mitosis_chromosome.py`; проверка матриц, анимации, экспериментальной сборки и уровней детализации: `node tools/verify-kinetochore.mjs`.

## Анафаза: снятие когезии

`blender/models/cohesion_pdb.py` строит домены по [7NJ1](https://www.rcsb.org/structure/7NJ1) (Yu et al., 2021, сепараза–секурин; [статья](https://doi.org/10.1038/s41586-021-03764-0)) и [6WG3](https://www.rcsb.org/structure/6WG3) (Shi et al., 2020, когезин–NIPBL–ДНК). Данные RCSB PDB — CC0. Координаты исходных файлов находятся в `models_raw/pdb/` и не публикуются. В приложении источники доступны по кнопке «О моделях».

Крупный план `mitocohesin.js` использует настоящие формы сепаразы, секурина и глобулярных доменов SMC1/SMC3. Уточнение 17.11.2026: STAG1 из 6WG3; гистоны и обвивающая их ДНК — из уже имеющейся 1KX5 (Davey et al., 2002). Показаны два небольших фрагмента хроматина с нуклеосомами, а не целые хроматиды. Спиральные плечи SMC, шарнир, гибкий RAD21, соединительные участки ДНК, расщепление и взаимное положение доменов — учебная реконструкция раскрытого состояния; это не единственная конформация когезина. При открытии оба плеча остаются соединены общим шарниром. 6WG3 представляет инженерный комплекс загрузки с заменами RAD21 R172A/D279A/R450A, а не нативный комплекс когезии сестёр; здесь показаны только его домены, а не расщепление этого мутантного конструкта. 7NJ1 представляет ингибированную сепаразу; анимация освобождения и катализа не является вычисленной атомной траекторией. Один показанный комплекс объясняет снятие множества центромерных связей. ДНК в анимации не разрезается.

Этап `mitoanaphase.js`: проверка 16 двуполюсных прикреплений → попытка разойтись при сохранённой когезии → освобождение сепаразы → выбор белковой мишени → расщепление RAD21 → объяснение причины → синхронное расхождение → вопросы. Олимпиадный уровень дополняет цепь APC/C–Cdc20 → разрушение секурина/циклина B и различает анафазы A/B и наборы всей клетки/полюсной группы. Проверка: `node tools/verify-anaphase.mjs`.
