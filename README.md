# Генетика — путь «от молекулы к признаку»

Тренажёр по генетике и молекулярной биологии для учащихся 9–11 классов: интерактивные 3D-уроки и задачи с разбором типичных ошибок.

**Открыть в браузере:** https://azzp1d.github.io/genetika/

Работа для республиканского конкурса «Компьютер. Образование. Интернет» (КОИ-2026), номинация «Дидактический конструктор: система учебных модулей».

## Что внутри
- `app/` — само приложение (HTML, JavaScript, библиотека Three.js). Работает в браузере; для Android оборачивается в приложение с помощью Capacitor.
- `blender/` — скрипты, которыми построены собственные 3D-модели органоидов (Blender 5.2).
- `tools/` — вспомогательные скрипты.

Все 3D-модели созданы для этого проекта. Разработка велась автором с использованием ИИ-инструмента Claude Code (Anthropic).
